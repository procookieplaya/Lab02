# Lab02
Second lab


Project Description: 
Create a marketplace where restaurants, cafes, bakeries, and home cooks can
sell surplus food at dynamically adjusted prices that decrease as expiration approaches. A
fresh sandwich at 2 PM might cost $8, but by 8 PM it's $3. Users discover great deals while
fighting food waste and helping the environment. The app creates urgency through real-time
pricing, gamifies sustainability, and turns inevitable waste into affordable meals.

Technologies/Tools that can be used:
Python, Java, Microsoft Word, App Development IDE

Steps on how to use the app:
1. Create an account, either a vendor or a customer
2. If customer, be able to see all vendors with their discounted prices and be able to purchase anything
3. If vendor, be able to set up your business on the application by inputting business details (name, logo, location, CR, etc).
4. Then the vendor, will be able to post any food item with its price and expiration date.
